# Start here: Keys of Hope report

`KeysOfHope_for_YWCA.zip` has what you need to run the Keys of Hope report in Power BI, the Microsoft program that shows the report. Download it, unzip it onto the C: drive, and open the guide inside.

## What is in the zip

- **`Keys of Hope.pbit`**
  The template. That is the starter file for the report. It holds no data.

- **`START HERE - Keys of Hope report.pdf`**
  The two-page guide. Open this first.

- **`exports`**
  An empty folder. Your four EmpowerDB export files go here.

## The weekly routine, in short

Every Friday: delete last week's files from `exports`. Export four tables from EmpowerDB and save them there. Open your saved `Keys of Hope` file (not the template), click `Refresh` on the `Home` tab, and check that `Last updated` shows today's date.

It takes about 5 minutes.

The first time takes about 10 minutes, on a Windows computer.

## The one safety rule

**Keep the export files on YWCA computers. Never email them.**

They hold records for every YWCA program.

## One honest note

So far, the report has only run on made-up data.

The first run on real records is the next step. When you do it, check every number against what your staff know.
